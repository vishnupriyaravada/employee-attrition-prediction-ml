Employee Attrition Prediction & Workforce Risk Analysis

This project uses Machine Learning to predict employee attrition and identify the key factors influencing employee turnover.

📌 Project Objective

Employee attrition can significantly impact organizations through increased recruitment costs, reduced productivity, and loss of experienced talent. This project develops a machine learning classification model to predict employee attrition using the IBM HR Analytics Employee Attrition dataset.

The project also identifies important factors influencing employee turnover and provides insights to support data-driven HR decision-making and employee retention strategies.

🛠️ Technologies Used
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Seaborn
Jupyter Notebook
📊 Machine Learning Models

The following classification models were developed and compared:

Logistic Regression
Decision Tree Classifier
Random Forest Classifier

Hyperparameter tuning was performed using GridSearchCV for the Random Forest model.

📈 Model Evaluation

The models were evaluated using:

Accuracy
Precision
Recall
F1 Score
ROC-AUC Score
Confusion Matrix

🏆 Best Model: Tuned Random Forest Classifier

Test Accuracy: 82.99%

🔍 Key Insights

The most influential factors affecting employee attrition included:

Monthly Income
Age
Total Working Years
OverTime
Distance From Home
Years At Company

The analysis showed that employees working overtime had a significantly higher likelihood of attrition.

💡 Business Recommendations

Based on the analysis, organizations can:

Review compensation policies
Monitor employee overtime and workload
Provide support at different career stages
Consider flexible work arrangements for employees with long commuting distances
Use predictive analytics to identify employees at higher risk of leaving

IBM HR Analytics Employee Attrition Dataset.
